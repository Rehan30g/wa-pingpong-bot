# Fase 4 — Media dan web (gate lokal otomatis selesai)

Status: **implementasi dan gate lokal otomatis selesai; uji WhatsApp langsung belum dijalankan karena menjadi tugas pengguna**. Implementasi ini dikerjakan langsung setelah pengguna menghentikan penggunaan Antigravity. Status ini bukan izin deploy atau klaim siap produksi.

Sudah dibuat:

- Video WhatsApp langsung/kutipan diekstrak menjadi satu frame JPEG dengan ffmpeg (maksimum 5 detik dan 2 MiB frame). Kegagalan konversi menghasilkan metadata video tanpa crash. `video_url` base64 tidak lagi dibuat oleh `group-agent`.
- Asset store privat sementara dengan ID acak, izin file 0600, scope chat/task, hash SHA-256, batas ukuran, dan TTL cleanup.
- `web_fetch` HTTPS hanya membaca teks, nonaktif secara default. Host harus ada dalam allowlist owner. Resolusi DNS menolak alamat privat dan hasil dipin pada koneksi TLS; redirect diperiksa ulang. Respons dibatasi 256 KiB, timeout 5 detik, hanya text/plain atau text/html.
- `web_search` publik melalui OpenRouter server tool Exa ditambahkan untuk `/task cari web <query>`, nonaktif secara default. Query dibatasi 240 karakter dan ditolak bila tampak mengandung kunci, token, email, atau nomor telepon. Tiap task dibatasi satu pencarian, tiga hasil, dan wajib memperoleh URL sitasi HTTPS dari respons provider. Probe OpenRouter nyata berhasil: satu request pencarian dan tiga sitasi; respons aktual memakai `usage.server_tool_use_details`, sehingga parser menerima bentuk itu serta bentuk `server_tool_use` di dokumentasi.
- Audit lanjutan egress: `web_fetch` dan `fetch_media_from_url` kini meneruskan AbortSignal dari registry sampai request HTTPS dan memeriksa pembatalan sebelum/setelah DNS. `web_fetch` meminta encoding identity lalu menolak respons terkompresi dan Content-Length di atas batas sebelum streaming. Web search memakai kuota host OpenRouter yang valid, tanpa retry otomatis agar tidak membuat pencarian berbayar ganda.
- `fetch_media_from_url` untuk JPEG/PNG/WebP tersedia tetapi nonaktif default; memakai host HTTPS allowlist, DNS pin, batas streaming 5 MiB, magic bytes, dan asset privat chat/task. URL sumber yang dicatat tidak menyimpan query/fragment.
- Perintah `/task web <URL>` dan `/task ambil gambar <URL>` hanya dirutekan bila flag capability terkait aktif. URL dengan query/fragment ditolak agar parameter rahasia tidak masuk task/trace. Egress berbagi kuota maksimum 4 request per task dan 20 request per host per menit; request tanpa task ID ditolak.
- `fetch_media_from_message` dan `/task media` memakai gambar pesan langsung/kutipan atau satu frame video yang masuk melalui dispatcher, disimpan ke asset privat chat/task dan diverifikasi ulang berdasarkan `entry_id`. Media hilang/gagal didekode membuat task gagal tertutup. Shadow memakai root asset terpisah. Tes dispatcher dengan mock socket membuktikan ACL dan jalur gagal.
- Audit integrasi menemukan checkpoint awal TaskRunner semula menimpa `evidence_refs` inbound. Itu sudah diperbaiki agar sumber media tetap tersedia setelah planner berjalan.
- `make_sticker` mengonversi gambar di proses anak tanpa environment rahasia, dengan batas input 5 MiB, piksel 16 juta, output 512 KiB, dan timeout 5 detik; hasil diverifikasi sebagai WebP 512×512 pada test. `/task stiker` menyambung asset sumber ke hasil melalui referensi runtime `$last_asset`.
- `send_asset` hanya menerima asset task/chat asal, tanpa argumen penerima. `/task kirim stiker` menulis outbox intent secara atomik dan task tetap `verifying` sampai receipt; mock socket membuktikan payload stiker benar. Crash sesudah send menjadi `delivery_uncertain`, tanpa kirim ulang buta; rekonsiliasi butuh konfirmasi eksplisit. Semua flag baru nonaktif default.
- Recovery startup menyelesaikan task asset ketika outbox sudah delivered tetapi proses mati sebelum status task ikut tersimpan. Asset yang melewati TTL dibersihkan berkala oleh lifecycle; root shadow yang sama dengan root agent ditolak.
- Review dispatcher menemukan mode agent sebelumnya bisa membuat task dari DM asing atau grup yang tidak ada di `allowedGroups`. Gerbang whitelist DM dan allowed group kini berlaku sebelum routing/DB task; test langsung membuktikan nol task dibuat untuk keduanya.
- `README.md` dan `.env.example` diperbarui. Runtime mendaftarkan capability web melalui registry; egress shadow ditolak dan mode agent memakai canary guard untuk side effect `external`.
- Audit lanjutan menemukan `export_archive` lama menghasilkan ID palsu dan status `exported` tanpa arsip. Capability tersebut kini nonaktif dan gagal tertutup; tes approval tetap menguji konsumsi izin tanpa mengklaim ekspor berhasil. `read_note` wajib menerima scope chat eksplisit. Pengenalan izin dari substring seperti `disallow_owner` juga diperketat ke prefix otorisasi yang dikenal.

Validasi lokal checkpoint sebelumnya: `npm test` **191/191 lulus**, `npm audit --omit=dev` **0 vulnerability**, `git diff --check` exit 0, sintaks file penting lulus. Probe ffmpeg nyata menghasilkan frame JPEG dari MP4 sintetis (2.104 byte video, 248 byte frame). Hash `ai-memory.json`, `agent-jobs.json`, dan `data.json` tetap sama seperti baseline. Sesudah tambahan web search, tes regresi dan probe live dijalankan lagi; lihat hasil turn terbaru, jangan menganggap angka checkpoint lama sebagai hasil final.

Validasi setelah web search: `npm test` **206/206 lulus**, `npm audit --omit=dev` **0 vulnerability**, `git diff --check` dan syntax checks exit 0. `npm run simulate:web-search` memakai API OpenRouter nyata dengan storage simulator sementara dan menghasilkan 3 sitasi dari 1 pencarian; tidak mengirim WhatsApp.

## Gate lokal final — 23 September 2026

- Kuota egress dipindahkan ke SQLite schema v2 (`egress_task_usage`, `egress_host_hits`) dengan reservasi transaksional. Tes dua request paralel, batas per task/host, restart koneksi DB, dan jendela satu menit lulus. Lifecycle memakai limiter durable untuk web search, web fetch, dan media URL.
- Gambar dari URL maupun pesan masuk kini diverifikasi di child process: magic bytes harus cocok dengan format hasil decode, pixel maksimal 16 juta, input maksimal 5 MiB, timeout 5 detik. Header PNG/JPEG palsu ditolak sebelum asset dipakai. Ini membatasi parser, tetapi child process bukan sandbox OS penuh; fitur tetap mati default sampai rollout.
- Tes adversarial tambahan menolak redirect ke DNS privat pada request kedua, encoding/Content-Length berbahaya, dan permintaan setelah AbortSignal dibatalkan. `send_asset` sudah diuji lewat mock socket hingga receipt, crash post-send, `delivery_uncertain`, rekonsiliasi, serta recovery startup. Uji WA langsung sengaja dilewati sesuai pembagian tugas dengan pengguna.
- Simulasi memori OpenRouter menemukan JSON compact terpotong dan koneksi provider yang putus dengan status HTTP 200. Compact kini mencoba ulang sekali dengan batas output lebih besar tanpa mengubah memori bila dua hasil tetap rusak; auto-compact tidak berputar tanpa henti saat gagal. Koneksi terputus setelah 200 diklasifikasi retryable. Tes regresi membuktikan memori dan history tidak hilang.
- Probe pencarian web dua kali timeout pada 30 detik, lalu lulus dengan timeout khusus 45 detik (satu pencarian dan dua sitasi). Tidak ada retry otomatis pada web search agar biaya tidak berlipat diam-diam. Ini menunjukkan latensi provider dapat melewati 30 detik; bukan jaminan performa produksi.
- `npm test` akhir **212/212 lulus**; tiga run berturut-turut setelah perubahan SQLite sebelumnya lulus **210/210** masing-masing. `npm audit --omit=dev` menunjukkan **0 vulnerability**; syntax checks dan `git diff --check` exit 0. Simulasi OpenRouter `simulate:ai`, `simulate:burst`, `simulate:memory`, `simulate:dm`, dan `simulate:web-search` berakhir sukses tanpa WhatsApp nyata.
- SHA-256 `ai-memory.json`, `agent-jobs.json`, dan `data.json` sesudah tes identik dengan baseline. File rahasia dan auth tidak diubah.

**Yang tidak termasuk kelulusan ini:** pengiriman/receipt WhatsApp nyata, penilaian manusia, sandbox OS untuk parser, shadow soak dan canary produksi. Pengujian WA langsung menjadi tugas pengguna; shadow/canary dan izin rilis adalah gate Fase 7. Default runtime tetap `legacy` dan flag capability Fase 4 tetap `false`.
